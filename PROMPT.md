
# Prodesk IT Shopzone – Sprint 6 Prompt

## Project Prompt

Build a modern, responsive, and user-friendly e-commerce shopping website called **Prodesk IT Shopzone**.

The website should provide users with a smooth shopping experience through a clean interface, product browsing, search functionality, and shopping cart interactions.

## Requirements

- Create a responsive e-commerce interface.
- Display products using attractive product cards.
- Show product name, image, price, and relevant information.
- Add a product search feature.
- Allow users to add products to the shopping cart.
- Allow users to remove products from the cart.
- Calculate the cart total dynamically.
- Provide a clean navigation structure.
- Make the interface responsive for desktop, tablet, and mobile devices.
- Use reusable and organized components where applicable.
- Maintain a simple and professional UI/UX design.

## Technology

Use modern frontend technologies such as:

- HTML5
- CSS3
- JavaScript
- React.js
- Vite

## UI/UX Guidelines

- Use a clean and modern layout.
- Maintain consistent spacing and typography.
- Make buttons and interactive elements easy to identify.
- Ensure responsive behavior across different screen sizes.
- Provide clear feedback for shopping cart actions.
- Keep the overall design simple and professional.

## Expected Result

The final application should function as a basic e-commerce shopping platform where users can:

1. Browse products.
2. Search for products.
3. View product information.
4. Add products to the cart.
5. Remove products from the cart.
6. View the total cart amount.
7. Use the website comfortably on different screen sizes.
